# 指标与基线规范 v2

更新日期：2026-10-31。本规范描述生产适配器的当前日值契约及显示算法，不是医学评估模型，也不是 COROS 官方恢复评分。五个字段已通过现有平台 COROS 连接观察；显示参数没有临床验证，更改它们必须更新规范与测试。

## 指标契约

| 轴 | 当前来源字段 | 内部单位 / 接受范围 | 向外含义 | 绘图范围 |
| --- | --- | --- | --- | --- |
| 睡眠质量 | 主睡眠报告的 `Sleep Score` | 分，0…100 | 分数较高 | 0–100 分 |
| HRV | `HRV Assessment` 中的 `HRV Avg` | ms，>0 | HRV 较高 | 0–150 ms |
| 静息心率 | 按日期返回的静息心率值 | bpm，>0 | 静息心率较低 | 40–100 bpm |
| 压力管理 | `Average Stress` | 分，0…100 | 平均压力较低 | 0–100 分 |
| 运动负荷 | `Load Ratio` | 比值，≥0 | 负荷比值较高 | 0–2 倍 |

这些字段是 2026-10-30 观察到的英文文本标签，不是 JSON 键名或 COROS 承诺的稳定 API。接受范围是本应用的校验规则，不宣称穷尽服务端所有版本的取值域。不能识别的量纲或格式使该轴不可用，不猜测字段、不自动缩放。[接入证据与适配版本](COROS_INTEGRATION.md)

HRV 只读官方按日评估中的均值，忽略 `Sleep HRV Time Series`，不重新平均原始采样点。静息心率不使用日平均心率替代。“压力管理”是本应用的轴名称，原值仍是平均压力。

负荷比值直接使用服务给出的按日 `Load Ratio`。它不是当日训练量，也没有本应用定义的“安全区间”；不拿卡路里、活动次数或周累计替代。滚动负荷指标的相邻日可能重叠，具体计算窗口仍需官方进一步确认，基线仅描述同一字段的近期分布，不作训练处方。如果返回形态变为周汇总或其他单位，必须停止此轴比较并更新契约。

## 日期、修订与缺失

观察日为 D；基线是同一本机时区的 **[D−30 日零点, D 日零点)**，当天是 **[D 日零点, D+1 日零点)**。全部边界用 Calendar 自然日运算，跨 DST、月和年不采用固定秒数。

时区自动跟随 Mac，无需用户填写。服务报告的自然日可能采用账号设置；本应用不宣称能由本机时区识别账号时区，返回日超出窗口或缺少今天时按严格契约降级，不擅自平移日期。系统时区改变后使用新作用域重新查询，旧历史不重新解释。睡眠保留 COROS 报告所属日，不反推入睡日；Core 不对它额外减一天。新快照只把 D 当日记录作为当前值，昨日值只能参与历史。

每轴、每天保留最新修订，先选修订再校验。当前英文报告没有稳定的来源更新时间，生产 `updatedAt` / `observedAt` 表示成功读取该日值的时间，不是生理测量时间，也不证明设备刚同步。失败重试不能改写它；相同更新时间保留先到记录。

成功报告中明确的 `No data` 写为缺失修订，旧值不得恢复。报告没有提及的日期不能推断为 `No data`，保留旧记录和原时间。若未确认今天，即便历史已经更新，本轴仍标记今日同步未完成。非法值修订也会阻止旧修订复活。私有历史保存这些缺失标记，按当前日保留 90 个自然日，详见 [存储架构](ARCHITECTURE.md#应用私有历史)。

历史仅采用 `isComplete == true`、非显式缺失且通过数值校验的日值。按轴独立计数，缺 HRV 不影响睡眠基线。NaN、无穷、越界值不能进入统计；0 不是通用缺失值：睡眠、压力、负荷的合法 0 保留，HRV 和静息心率的 0 不可用。

少于 7 个有效历史日时，基线及绘图指数为空，但当天原值仍可展示。7 是产品最低展示门槛，不是统计可靠性保证；始终显示 N/30 天。一次查询有 31 个日期不等于每轴已有 30 个有效历史值，仍需排除缺失与无效记录。

## 当天值与新鲜度

当天压力、静息心率、负荷标记为 `isProvisional`，表示日值仍可能变化。已返回的主睡眠和官方睡眠 HRV 日评估作为已完成夜间记录；后续成功读取仍允许修订。历史日期按已结束自然日处理，不额外推断设备覆盖时长。

当前指数可以显示暂定值，但同时标识“今日进行中”，不能把暂定点解释为恢复或训练建议。没有来源数据时不以 0、邻轴插值或上一日值补齐。

每轴单独判断时效：观察日不是当前账号日、最后成功读取已超过 6 小时、时间明显位于未来、或最近查询失败时标记待更新。新生成的快照时间只表明文件更新，不使缓存值变新；其他轴成功也不改变本轴时间。手动、前台或定时触发均使用同一时效规则。格式不支持、无数据、认证错误和同步失败使用固定本地原因，不向小组件保存服务错误原文。

## 显示刻度

每轴使用固定的显示范围，当天原值与过去 30 个完整日的中位数共用同一个变换：

```text
baseline = median(history)  // 至少 7 个有效日
fraction(value) = (clamp(value, lower, upper) - lower) / (upper - lower)
index(value) = 100 × fraction(value)        // 睡眠、HRV、负荷
index(value) = 100 × (1 - fraction(value))  // 静息心率、平均压力
todayIndex = index(today)
baselineIndex = index(baseline)
```

显示范围见上表。睡眠和压力采用字段的 0–100 范围；HRV、静息心率和负荷的范围是本项目的固定绘图参数，**不是临床正常范围、健康评分或 COROS 官方阈值**。不同量纲不直接相加，指数不用于跨人排名或面积总分。

基线不再固定在 50，也不必为规则五边形：历史中位数变化，虚线位置随之变化；当天值与基线相等时，两点重合。相同原值在不同日期和不同历史分布中保持相同位置，不能因当天极值而伸缩整张图。中位数仍用于降低单日历史极值的影响，历史窗口和缺失规则保持不变。

超出显示范围的有效值截到边缘，但保留原值；非法值仍按缺失处理。固定范围是展示裁剪，不是数据接受范围。少于 7 个有效历史日时仍不绘制该轴的比较线，显示当天原值和 N/30。快照升级到 v3，v2 的固定 50 指数不可直接复用，主应用重新同步或重新生成演示后写入新快照。

## 图形规则

- 固定轴序：睡眠质量 → HRV → 静息心率 → 压力管理 → 运动负荷。
- 当前实线与基线虚线依靠线型和文字区分，不只依靠颜色。
- 缺轴时只画已知点或连续段，不绘制完整填充面积，不填零或插值。
- 当前没有数据但历史充足时，仍可显示基线及“暂无当日数据”。
- 主应用各轴展示原值、单位、基线和样本数；小组件按尺寸精简，中号以小字在轴旁标注原值，大号在轴旁保留原值，并在雷达下方展示精简数据表。图表辅助功能描述保留原值、基线、样本数与状态，完整信息可在主应用查看。平均压力的原始数值与图上方向相反，必须说明。
- 运动负荷向外不表示恢复更好；不计算面积总分，不输出诊断或运动处方。
- 失败后保留的同日值带原时间及失败状态；旧日缓存带日期和陈旧提示。
- 全部演示快照带 `isDemo`，生产解析失败不使用演示数据。
