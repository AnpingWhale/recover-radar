# 实施路线

更新日期：2026-10-30。M1 生产接入代码和 M2 的存储 / 同步基础已实现，原生授权与桌面端到端验收尚未完成。按验收门槛推进，阶段编号不代表发布日期承诺。

## M0 · 初始化与架构

- [x] Git 仓库、SwiftPM 共用模块、无第三方依赖。
- [x] 原生 SwiftUI 主应用与 WidgetKit 扩展工程。
- [x] 五轴雷达图、明确标识的合成演示、个人 30 日基线算法。
- [x] App Group 快照读写、核心测试、文档和 CI 配置。
- [ ] 完整 Xcode 无签名编译与实际签名安装；本轮环境只有 Command Line Tools。
- [ ] 真实桌面的 medium / large、浅深色、VoiceOver 和日期切换验收。

## M1 · COROS 接入代码与契约

- [x] 原生区域发现、动态注册、默认浏览器入口、state、PKCE、Keychain 和刷新轮换实现。
- [x] 记录 CN 拒绝自定义回调的兼容性结果；改为先绑定随机 loopback 端口，再使用一致 URI 注册、授权和交换令牌。
- [x] loopback 监听范围、8 KiB 上限、Host / path / state 校验、超时和取消关闭。
- [x] 断开与本地凭证删除、远端尽力撤销、取消和连接代次隔离。
- [x] MCP 初始化、JSON / SSE、工具分页、输入 schema 校验及五工具读取允许列表。
- [x] 通过现有平台 COROS 连接观察五工具文本；本次每项均有 31 个日期。
- [x] 严格英文日值解析：睡眠分、官方 HRV Assessment 均值、静息心率、平均压力、负荷比值。
- [x] 人工合成报告测试；不把真实用户数据写入 fixture。
- [ ] 原生应用 loopback 随机端口动态注册、真账号默认浏览器登录与回跳、取消和真实令牌轮换验收。
- [ ] 确认各区域实际兼容性；进一步确认负荷比值的官方滚动计算窗口。

验收应区分“平台连接已得到结果”和“本应用已完成授权”。缺失、未知格式和不足 30 天历史必须准确展示，不能把令牌描述为具有未证实的服务端只读权限。详见 [接入门槛](COROS_INTEGRATION.md#验收门槛)。

## M2 · 可靠的日常使用

- [x] `SyncCoordinator` 合并并发触发、逐轴错误处理及停止后再清理。
- [x] 私有 90 自然日历史，按连接 UUID、区域、时区隔离，原子保存和最新修订优先。
- [x] 仅替换响应明确确认的日期，`No data` 保留缺失修订；缺失日期不推断为撤回。
- [x] 快照 v3：固定刻度下的双序列指数（拒绝旧 v2），以及逐轴日期与读取时间、缺失 / 失败原因、连接状态、同步状态和最后尝试时间。
- [x] 只读请求有限重试、429 等待策略、401 受控刷新及保留旧缓存。
- [x] 主应用连接、取消、手动同步、运行中约每小时同步、回前台按需同步、菜单栏和可选登录启动入口。
- [x] Command Line Tools 开发预览脚本，独立 bundle / Keychain / 私有快照，明确不安装 Widget；预览禁用登录启动。
- [x] 本机时区自动配置，首次地区推定，已有授权区域固定；系统时区改变后重建日期作用域。
- [x] 与扩展共用内容视图的中 / 大号视觉画廊、浅 / 深色切换及 PNG 导出，实际窗口交互已验证。
- [ ] 完成这些入口在正式签名应用中的集成验收，确认系统登录项和 loopback 沙盒权限。
- [ ] 真机验证离线、授权过期、睡眠唤醒、跨日、部分失败、换号和本地数据删除。
- [ ] 验证用户完全退出应用后，Widget 正确显示旧时间和陈旧状态。

当前每轮重取 31 日窗口覆盖补传和修订；按缺口增量请求是后续优化，不属于已实现承诺。Widget 只读快照，不访问网络或凭证；主应用退出后没有隐式后台 daemon 继续同步。
